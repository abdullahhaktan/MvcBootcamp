## ✨ Temel Özellikler

### Mimari ve Tasarım Desenleri
* **ASP.NET Core MVC** mimarisini baştan sona uygulamalı olarak kapsar.
* **Katmanlı Mimari (n-Tier Architecture)** ve bu mimariye uygun olarak **Generic Repository** ve **Unit of Work** tasarım desenleri kullanılmıştır.
* **Dependency Injection (Bağımlılık Enjeksiyonu)** ve **Inversion of Control (IoC)** prensipleri uygulanmıştır.

### Veritabanı ve Veri İşlemleri
* **Entity Framework Core** kullanılarak veritabanı işlemleri yönetimi.
* Veritabanı modellemesi için **Code First** yaklaşımı.
* Veri transferi için **Data Transfer Objects (DTOs)** kullanımı.
* Uygulama genelinde temel **CRUD (Create, Read, Update, Delete)** operasyonları.

### Özellikler ve Kullanım
* **Identity** yapısı ile kullanıcı kayıt, kimlik doğrulama (**Authentication**) ve yetkilendirme (**Authorization**) işlemleri.
* Projenin farklı bölümlerini yönetmek için **Area** yapısının kullanımı.
* Görünüm bileşenlerini yeniden kullanılabilir hale getirmek için **Partial Views** ve **View Components** kullanımı.
* Formlar ve veri modelleri için **Validasyon (Doğrulama)** işlemleri.

## 💻 About the Project

## ✨ Core Features

### Architecture and Design Patterns
* Comprehensively covers the **ASP.NET Core MVC** architecture through practical application.
* Implements **Layered Architecture (n-Tier)**, alongside the **Generic Repository** and **Unit of Work** design patterns.
* Applies principles of **Dependency Injection (DI)** and **Inversion of Control (IoC)**.

### Database and Data Operations
* Database operations management using **Entity Framework Core**.
* Utilizes the **Code First** approach for database modeling.
* Implementation of **Data Transfer Objects (DTOs)** for efficient data transport.
* Core **CRUD (Create, Read, Update, Delete)** operations across the application.

### Features and Usage
* Implements **Identity** for user registration, **Authentication**, and **Authorization** via roles.
* Use of **Area** structure to manage different sections of the project.
* Utilizes **Partial Views** and **View Components** for reusable view components.
* Includes **Validation** processes for forms and data models.
